# persona/ · 人格与说话契约（骨架）

**职责**：用**配置**而不是代码分支描述「谁在说话」——称呼、语气、能说什么、不能说什么、什么时候闭嘴。

**契约要点**：

- 一人一份，互不可见；换人格不改程序；
- 明确的禁区（不编造、不替主人做主、不泄露另一个人的隐私）；
- 明确的沉默条件（对方在忙、刚说过、没话可说）；
- 不确定的词句照抄，不替主人解释成性格。

**对外接口**：无 HTTP 接口；人格文件由 `config.example.json` 的 `agents[].persona_file` 指向。

**不在本仓库**：任何人格正文与提示词。这里只留空目录与规则形状。
