# diary/ · 日记与情绪（骨架）

**职责**：白天给对话打情绪分，夜里写一篇日记；让"情绪"和"记忆"都有出处。

**契约要点**：

- **当天对话是唯一事实来源**：日记里的每件事都要能在当日对话里找到影子，不凭空编；
- 一天一篇：重复写入视为修订，不生成第二篇；
- 情绪分 0–1，映射到离散档位；只做参考，不参与"该不该回话"以外的决策；
- 归档后按日期可查、可按月索引。

**对外接口**：`GET /api/diary`、`GET /api/diary/list`、`GET /api/diary/calendar`、`GET /api/emotion/history`。

**不在本仓库**：打分模型、日记生成提示词、归档格式、定时任务实现。
