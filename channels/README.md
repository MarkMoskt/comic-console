# channels/ · 即时通讯通道（骨架）

**职责**：一个通道 = 一个机器人实例 + 一个真实的人。负责收发、去重、限速、断线重连、登录确认。

**契约要点**：

- 入站消息归一化为 `{channel, agent, peer, text, ts, msg_id}`；
- 出站按气泡逐条发送，一条一句；
- 同一 `msg_id` 只处理一次（重连会重放）；
- 单通道有发送速率上限，超限排队或丢弃，不刷屏；
- 登录确认码只扫最近日志，不回溯历史。

**对外接口**：`POST /api/login/request`、`GET /api/login/poll`、`POST /api/login/logout`。

**不在本仓库**：任何平台的协议适配、扫码/登录流程、媒体上传下载实现。
