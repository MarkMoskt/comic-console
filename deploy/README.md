# deploy/ · 部署与回滚（骨架）

**职责**：把本地改动安全地落到线上，并且随时能退回去。

**必须有的四个不变量**：

1. **先 diff 再传**：有一条只读的预演路径，不写任何东西；
2. **覆盖前先备份**：线上同名文件转成带时间戳的备份，这是唯一的即时回滚点；
3. **传完校验哈希**：不一致就中止，不算发布成功；
4. **发布后跑冒烟**：只读断言全绿才算成功，否则立即回滚。

**额外约定**：

- 备份不落在交付目录里，避免污染下一次 diff；
- 换程序文件必须重启服务才生效，换静态页不必；
- 冒烟只做只读断言，绝不写线上数据。

**对外接口**：无；这是运维脚本，不暴露到网络。

**不在本仓库**：任何部署脚本、服务器地址或凭据。
