# memory/ · 四层记忆（骨架）

**职责**：让系统在第 365 天还能答上第 1 天说过的话，而不是把全部历史塞进上下文。

| 层 | 存什么 | 关键约束 |
| --- | --- | --- |
| 会话 | 最近若干轮原文 | 按 agent × 身份分键 |
| 事实 | 稳定信息（喜好、约定、关系） | 去重、可衰减、可追溯来源 |
| 向量库 | 文档切块 + 向量 | 文档变更后重算，计数只有一个出口 |
| 检索 | 三层统一召回 | 相关度 × 时效，取前若干条 |

**对外接口**：`GET /api/memory?q=`、`GET /api/status` 的 `counts`。

**不在本仓库**：存储引擎、切块策略、嵌入模型调用、去重与衰减算法。
